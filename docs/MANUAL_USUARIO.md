# Manual de usuario

## Acceso

Abre la aplicación e inicia sesión como `alumno` o `admin`, con la contraseña de prueba `1234`. Usa **Cerrar sesión** en el menú lateral al terminar.

## Consultar y registrar incidencias

En **Incidencias**, utiliza la búsqueda y los filtros de estado y prioridad. El contador indica cuántas incidencias coinciden. Abre el menú lateral y selecciona **Nueva incidencia** para escribir un título, una descripción de al menos 10 caracteres y una prioridad. Pulsa **Guardar incidencia**. La incidencia aparece como **Pendiente**.

## Funciones del administrador

En **Incidencias**, cambia el estado con el selector de cada fila. En **Panel de control**, consulta los totales y el gráfico. **Descargar CSV** guarda todas las incidencias actuales, aunque haya filtros activos en el listado. **Informe PDF** abre el informe en otra pestaña: pulsa **Imprimir o guardar como PDF** y selecciona el destino PDF del navegador. Si el navegador bloquea la pestaña, permite ventanas emergentes para esta aplicación e inténtalo de nuevo.

En **Fuentes de datos de demostración**, pulsa **Cargar fuentes simuladas** para ver dos ejemplos de datos que llegan de forma asíncrona. Son archivos JSON locales: uno representa filas SQL/REST y otro documentos NoSQL.

## Importante

Esta versión es una práctica: los datos nuevos se pierden al recargar y las cuentas de prueba no protegen información real. La aplicación no se conecta a bases de datos reales.
